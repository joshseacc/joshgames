Source: Supp WS 4 Both Editions

Are there any ...?

[圖片 Placeholder: Illustration of stationery on a desk (Source: Supp WS 4)]

We use "Are there any ...?" to ask if there is something.

Are thereanyscissors / crayons / needleson the table?

Grammar Tips

  • Yes, there are.
  • No, there aren't.
  • there aren't = there are not
  • We use 'Are there any...?' for countable nouns.

Source: Supp WS 6 Both Editions

What's the + (noun) + like?

We use "What's the + (noun) + like?" to ask someone to describe something.

What'sthe weather / the foodlike?

We use "It's + (adjective)." to answer.

It'ssunny / yummy!

Grammar Tips

  • • A noun is a thing, person or place.
  • • A noun after 'What's the...' must be singular.
  • What's = What is
  • • We use an adjective to describe something.
  • It's = It is

Imperatives (祈使句)

Source: Supp WS 6 Both Editions

Rules

We use imperatives to tell people what to do.

  • Be quiet!
  • Take an umbrella.

We use imperatives to tell someone what not to do.

  • Don't run!
  • Don't shout.
Grammar Tip: Use a capital letter at the start of a sentence.
