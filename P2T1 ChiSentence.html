二年級中文科溫習筆記與練習

一、 改寫句子：人稱轉換

📖 句式範例（第一人稱改為第三人稱）

原句：我愛白色，常常穿着白色的裙子。

目標：她愛白色，常常穿着白色的裙子。

原句：我喜歡打籃球，剛剛加入了學校的男子籃球隊。

目標：他喜歡打籃球，剛剛加入了學校的男子籃球隊。

✍️ 練習（把「我」改為第三人稱「他」或「她」）

  1. 我每天都會在公園跑步，希望能鍛鍊身體。
  2. 我最喜歡吃的水果是西瓜，因為它很解渴。
  3. 昨天我和媽媽一起去圖書館借書。

二、 改寫句子：加入連詞「還」

📖 句式範例

原句：小豬吃了一個蛋糕。小豬吃了一根玉米。

目標：小豬吃了一個蛋糕，還吃了一根玉米。

原句：表哥會說普通話。表哥會說日語。

目標：表哥會說普通話，還會說日語。

✍️ 練習（把兩句合併成一句）

  1. 哥哥會彈鋼琴。哥哥會拉小提琴。
  2. 猴子喜歡吃香蕉。猴子喜歡吃蘋果。
  3. 爸爸幫我檢查功課。爸爸教我溫習默書。

三、 改寫句子：運用疊詞 (AABB)

📖 句式範例

原句：下雨了，小雞急忙地跑回家。

目標：下雨了，小雞急急忙忙地跑回家。

原句：今天小兔打扮得漂亮。

目標：今天小兔打扮得漂漂亮亮。

✍️ 練習

  1. 同學們（高興）地迎接新學年的開始。
  2. 弟弟把房間收拾得（整齊）。
  3. 大家都（平安）地度過了這次颱風。

四、 句式仿作：「......一......，......就......。」

📖 句式範例

原句：小弟弟哭，外婆拿出糖果哄他。

目標：小弟弟一哭，外婆就拿出糖果哄他。

原句：媽媽出門，妹妹哭起來。

目標：媽媽一出門，妹妹就哭起來。

✍️ 練習

  1. 上課鐘聲一響，同學們就 。
  2. 爸爸一 ，小狗就開心地搖尾巴。
  3. 一 ， 就 。

五、 句式仿作：「......，便......。」

📖 句式範例

原句：姐姐肚子餓了。姐姐到快餐店吃東西。

目標：姐姐肚子餓了，便到快餐店吃東西。

原句：姐姐收拾桌面後。姐姐做功課。

目標：姐姐收拾桌面後，便做功課。

✍️ 練習

  1. 我做完家課後，便 。
  2. 媽媽買了新鮮的食材回家，便 。
  3. 老師走進課室，大家便 。

六、 擴寫句子：加入適當的詞語

📖 句式範例

原句：虎媽媽說：「我有這麼孝順的孩子，多開心啊！」

目標：虎媽媽滿意地說：「我有這麼孝順的孩子，多開心啊！」

原句：獅子大王警告大灰狼：「你不可以再傷害森林裏的小動物。」

目標：獅子大王鄭重警告大灰狼：「你不可以再傷害森林裏的小動物。」

✍️ 練習（選詞填空：大口大口地 / 美麗的 / 溫柔地 / 興奮地）

  1. 花園裏開滿了 花朵。
  2. 弟弟 吃着美味的雪糕。
  3. 媽媽 對我說：「下次要小心一點啊！」

七、 續寫句子：「......，有的......，有的......。」

📖 句式範例

例句：公園裏的遊人，有的看花，有的踢球。

例句：家裏的人，有的看書，有的畫畫。

✍️ 練習

  1. 操場上的同學很多，有的 ，有的 。
  2. 玩具箱裏有許多玩具，有的 ，有的 。
  3. 超級市場裏的貨品真多，有的 ，有的 。

八、 續寫句子：「......，可是......。」

📖 句式範例

例句：小豬做的蛋糕不好看，可是很好吃。

例句：馬爸爸帶着小馬到森林探望山羊伯伯，可是他不在家。

✍️ 練習

  1. 雖然這道數學題很難，可是 。
  2. 我很想去公園玩，可是 。
  3. 妹妹跌倒了，可是 。

九、 連詞填空 (所以、因為、可是)

📖 句式範例

例句：外面下着大雨，(所以) 我們不能去遊樂場玩了。

例句：(因為) 我病了，(所以) 媽媽不讓我上學。

例句：今天天氣寒冷，(可是) 叔叔只穿着單薄的衣服外出。

✍️ 練習（填上：所以、因為、可是）

  1. ( ) 弟弟每天勤力練習，( ) 他的字寫得越來越好。
  2. 我已經吃得很飽了，( ) 桌上的甜品太吸引，我忍不住又吃了一口。
  3. ( ) 忘記帶雨傘，( ) 哥哥的衣服都被雨淋濕了。
